# Tixcash OLTP Service

Online Transaction Processing service for the Tixcash network.

## Overview

The OLTP service handles high-throughput transaction processing for the Tixcash blockchain, including:

- Real-time transaction submission and validation
- Transaction status tracking
- Account balance management
- Batch processing for high-volume operations

## Tech Stack

- .NET / ASP.NET Core
- SQL Server for transaction persistence
- Optimized for high-concurrency workloads
